# Apimook Sarovath — Portfolio (v2)

A rebuild of the portfolio at [finmook.github.io/Portfolio](https://finmook.github.io/Portfolio/) using **Next.js (App Router) + TypeScript + MUI**, with a dark, modern tech-portfolio look.

## Stack

- **Next.js 16** (App Router)
- **React 19**
- **MUI 9** 
- **TypeScript**
